# Cvičení 7.6 — Debug: čtyři chyby v jedné obrazovce

| # | Vinný řádek                                                                                                   | Proč se to děje                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Oprava                                                                                                 |
|---|---------------------------------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------|
| A | var novyNazev = ""                                                                                            | Obyčejná lokální proměnná. Není sledovaná: `onValueChange` ji sice přepíše, ale Compose o změně neví, funkci znovu nespustí a pole dál dostává `value = ""`. Do pole proto „nejde psát“. A zároveň se proměnná při každé rekompozici (třeba po smazání města) vytvoří znovu s hodnotou `""`. Tlačítko Přidat čte tutéž obyčejnou proměnnou, takže se chová nevyzpytatelně: podle toho, co do ní naposledy zapsal `onValueChange`, nepřidá nic, nebo přidá nesmyslný název (typicky jen naposledy napsané písmeno). Žádná chyba se nehlásí, protože kód je z pohledu Kotlinu naprosto v pořádku. | var novyNazev by rememberSaveable { mutableStateOf("") }                                               |
| B | .padding(8.dp)<br>.background(…)                                                                              | `padding` zmenší prostor pro vše, co je za ním v řetězu, takže `background` vybarví jen ten zmenšený obdélník — barva těsně obepíná písmena a mezera zůstane nevybarvená. Zamýšlený odznak potřebuje pořadí obrácené.                                                                                                                                                                                                                                                                                                                                                                           | .background(…)`<br>`.padding(horizontal = 12.dp, vertical = 4.dp)                                      |
| C | items(mesta) { … }                                                                                            | Chybí `key`. Stav `rozbaleno` uvnitř položky se proto váže na pozici v seznamu, ne na položku. Smazáním „Zlín“ (index 0) se všechny další položky posunou o jednu pozici výš (na nižší index); Compose to interpretuje jako „položka na indexu 2 změnila obsah“, ne „položka zmizela“, a stav `rozbaleno = true` zůstane na indexu, kde byl. Výsledek: rozbalená je jiná položka.                                                                                                                                                                                                               | items(items = mesta, key = { it }) { … }<br>— a lépe: nahradit `String` třídou `Mesto` s vlastním `id` |
| D | Text("Přidat")<br>Text("Název města")<br>Text("Počet měst: …")<br>Text("Smazat")<br>Text("Teplotu doplníme…") | Texty natvrdo v kódu. Aplikace funguje, ale nejde lokalizovat, nejde je změnit bez překladu kódu, a porušuje to pravidlo z lekce 06. Studio ani Lint na ně v Compose kódu neupozorní (kontrola natvrdo zapsaných textů hlídá jen XML), takže je musí najít člověk.                                                                                                                                                                                                                                                                                                                              | Text(stringResource(R.string.mesto_pridat))<br>… a odpovídající položky ve `strings.xml`               |

# MeteoDenik

Semestrální projekt předmětu Mobilní technologie (UTB FAI, 1. ročník navazujícího studia SWI).

Aplikace bude sloužit jako osobní deník počasí: uživatel si k datu zapíše teplotu,
oblačnost a krátkou poznámku, záznamy uvidí v přehledném seznamu a k aktuálnímu dni
si nechá předplnit hodnoty z veřejného meteorologického REST API.
